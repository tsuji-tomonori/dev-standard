# Evidence map

確認日: **2026-09-30**。書誌はWeb検索後、原著、著者の公開版、出版社または発行機関のページで照合した。公開abstract・previewだけを確認した資料は、その範囲を表に明記する。未確認のDOIや研究効果を補わない。

区分は[全Skillの根拠監査](../../../../docs/reference/skill-evidence-audit.md)に従う。`R`は査読研究、`N`は規格・公式assurance guidance、`G`は公式実務資料や設計指針、`L`はこのrepositoryの方針。これらの資料だけから対象productの永続義務を作らない。

既存の[傾聴のevidence map](../../calibrated-collaborative-listening/references/evidence-map.md)は、理解された感覚、意味保持、トーンの詳しい根拠を担う。ここでは新規productの多ラウンド聞き取りに追加する判断を示す。研究からLLMの要件網羅性・完全実装・最適質問数を保証しない。

## 照合・更新の境界

書誌確認と全文検証を分ける。ISOの有料本文、APA等の一部本文への取得制限があるため、確認した公開部分だけを根拠にする。NASA、Pew、著者受理稿の観点はそれぞれの区分を保ち、規格本文を読んだ証拠として代用しない。

この確認で参照したpublisher・発行機関の表示範囲では、採用した用法を変更する訂正・撤回の通知は確認されなかった。これは全databaseを通した訂正・撤回不在の保証ではない。保守時に版、publisherの通知、DOIの遷移先を再確認する。実行transcript、検索生ログ、評価用personaは本mapへ保存しない。
